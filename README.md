# Quiz de Esportes

Um quiz interativo sobre conhecimentos gerais do mundo dos esportes, desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Perguntas de múltipla escolha.
- Cinco perguntas sobre esportes.
- Contagem de pontuação.
- Exibição do resultado final.
- Opção para jogar novamente.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Objetivo

Projeto desenvolvido para praticar conceitos de desenvolvimento web e aprender a utilizar recursos do GitHub, como repositórios, Issues, Branches, Pull Requests, GitHub Actions e GitHub Pages.
